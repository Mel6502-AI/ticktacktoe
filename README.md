# Tic Tac Toe

A two-player tic-tac-toe game built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Features

- Classic 3×3 two-player gameplay (X vs O)
- Live score tracking for wins and draws
- Winning line highlight with animation
- Reset board or reset all scores

## Scripts

| Command        | Description          |
|----------------|----------------------|
| `npm run dev`  | Start dev server     |
| `npm run build`| Production build     |
| `npm run preview` | Preview production build |
